A simple Tic Tac Toe game built using Java.
This is a 2-player console-based game where players take turns placing their marks (X or O) on a 3×3 board until one wins or the game ends in a draw.

📌 Features
 - 2-player mode (X vs O)
 - Console-based board display
 - Input validation for rows and columns
 - Detects win conditions (row, column, diagonal)
 - Detects draw conditions

🛠️ Technologies Used
 - Java (Core Java, OOPs)
 - Scanner (for user input)
 - 2D Arrays (to represent the board)

▶️ How to Run
Compile the program:
 - javac TicTacToe.java

Run the program:
 - java TicTacToe

🎯 Game Rules
 - The board is 3 × 3.
 - Player X always goes first.
 - Players take turns placing their symbol in an empty cell.
 - The first player to align three symbols (horizontally, vertically, or diagonally) wins.
 - If the board is full and no one has won, the game ends in a draw.
